# 🍽️ Halal Restaurant Finder

A Python CLI application demonstrating core programming fundamentals through a real-world problem.

**Portfolio Project | Built in 2 Hours | All Python Basics in One App**

---

## What It Does

This app helps you find, search, filter, and discover halal restaurants in LA!

- ✅ Search restaurants by name
- ✅ Filter by cuisine type  
- ✅ View all restaurants
- ✅ Sort by rating (highest first)
- ✅ Clean, organized interface

---

## Python Fundamentals Demonstrated

| Concept | How It's Used |
|---------|---------------|
| **Variables** | Store user input, search queries, results |
| **Strings** | Restaurant names, prompts, formatted output |
| **Lists** | Collection of all 8 restaurants |
| **Dictionaries** | Each restaurant's data (name, cuisine, rating, location, price) |
| **Functions** | `search_by_name()`, `filter_by_cuisine()`, `display_restaurants()` |
| **Loops (for)** | Loop through restaurants to search/filter |
| **Loops (while)** | Main app loop - keeps running until user exits |
| **Control Structures** | if/elif/else for menu selection & validation |
| **Comments** | Document every function and section |
| **File Imports** | Import restaurant data from separate file |

---

python3 finder.py
